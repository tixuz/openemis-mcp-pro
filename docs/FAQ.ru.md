# OpenEMIS MCP Pro — Часто задаваемые вопросы

---

## Что такое OpenEMIS?

OpenEMIS — бесплатная открытая школьная информационная система, разработанная ЮНЕСКО и KORDIT. Она обеспечивает повседневное администрирование учебных заведений — учеников, персонал, посещаемость, оценивание, инфраструктуру, питание, стипендии и отчётность на уровне министерства. OpenEMIS используется в детских садах, начальных и средних школах, профессиональных учебных заведениях и университетах стран-членов ЮНЕСКО. Сайт: [openemis.org](https://www.openemis.org); API: [api.openemis.org/core](https://api.openemis.org/core).

---

## Что такое MCP-сервер OpenEMIS?

openemis-mcp-pro — MCP-сервер чтения и записи (Model Context Protocol), соединяющий ИИ-ассистентов с любым экземпляром OpenEMIS. Он предоставляет девять инструментов, позволяющих агентам — Claude, ChatGPT, Cursor — отвечать на вопросы об управлении образованием и создавать записи без написания кода. Работает через stdio (локально) или HTTP (удалённый сервер для ChatGPT Custom GPT). Это pro-дистрибутив — с инструментами записи; бесплатная версия только для чтения: [openemis-mcp](https://github.com/tixuz/openemis-mcp).

---

## О чём можно спрашивать через этот MCP?

Вы можете запрашивать любой из 678 ресурсов OpenEMIS Core 5.13.0: ученики (зачисление, профили, контакты, особые потребности), персонал (должности, квалификации, посещаемость, отпуска), посещаемость учеников (ежедневные перекличка, история отсутствий, хронические прогульщики), оценивание (экзаменационные оценки, табели), риски учеников и баллы раннего предупреждения, профили учреждений, инфраструктура, питание, расписания. Вы также можете писать: отмечать посещаемость, зачислять учеников, вносить оценки, фиксировать инциденты поведения. Полный список — в [Плейбуках](playbooks/).

## Как это помогает управлению образованием?

REST API OpenEMIS Core предоставляет 3361 эндпоинтов для 678 ресурсов — слишком много для ИИ-агента. openemis-mcp-pro решает это с помощью обнаружения в рамках домена: `openemis_discover(topic)` сужает область до ~20–30 эндпоинтов, актуальных для конкретного вопроса. 40 курируемых плейбуков кодируют экспертные знания об именах полей, составных первичных ключах и правилах workflow, позволяя агентам отвечать на вопросы за 2–4 вызова инструмента.

## Как отслеживается посещаемость учеников?

В OpenEMIS используется модель «отсутствие по умолчанию означает присутствие»: при проведении переклички только не присутствующие ученики создают строки в `student-attendance-marked-records`. Строка содержит `absence_type_id` (Оправданный, Неоправданный, Опоздание). Для отметки посещаемости используйте плейбук [Отметка посещаемости учеников](playbooks/mark-student-attendance.ru.md); для просмотра статистики — [Просмотр последней посещаемости](playbooks/view-latest-attendance.ru.md).

## Как выявляются риски учеников?

OpenEMIS рассчитывает индивидуальные баллы риска на основе посещаемости и успеваемости. При превышении порога срабатывают правила оповещений. Данные хранятся в `institution-student-risks` и `student-risks-criterias`; случаи опеки — в `institution-cases`. Плейбук [Просмотр профиля рисков ученика](playbooks/view-student-risks.ru.md) возвращает баллы и открытые случаи. Плейбук [Просмотр сводки по рискам учреждения](playbooks/view-institution-risks.ru.md) показывает конфигурацию раннего предупреждения на уровне учреждения.

## В чём разница между приёмом и зачислением?

Приём — этап подачи заявки, при котором запись потенциального ученика проходит workflow-утверждение перед принятием. Зачисление — активная запись после одобрения приёма. При включённом обходе workflow возможно прямое зачисление через API — см. плейбук [Зачисление нового студента](playbooks/enroll-new-student.ru.md). Полный workflow приёма требует интерфейса приложения OpenEMIS.

---

## Какие уровни образования поддерживает OpenEMIS?

OpenEMIS поддерживает детские сады, начальные и средние школы, средние профессиональные учебные заведения, технические колледжи и университеты. Каждое учреждение имеет `institution_type_id`, определяющий доступные модули и структуры классов. Публичный демо-сервер [demo.openemis.org](https://demo.openemis.org/core) включает 24 учреждения разных уровней.

## Является ли это бесплатным?

Да — сам OpenEMIS бесплатен и с открытым исходным кодом (лицензия MIT). Бесплатный сервер openemis-mcp ([github.com/tixuz/openemis-mcp](https://github.com/tixuz/openemis-mcp)) также распространяется по лицензии MIT и охватывает все 678 ресурсов для чтения. openemis-mcp-pro (данный дистрибутив) добавляет инструменты записи, HTTP-режим сервера для ChatGPT Custom GPT и аутентификацию на уровне пользователя; распространяется по лицензии BSL 1.1 для тарифов Individual Pro, Institution Pro и Country Pro. Контакт: khindol.madraimov@gmail.com.

## Какие данные о персонале можно запрашивать?

openemis-mcp-pro позволяет получать: личные данные сотрудников (`security-users`), историю трудоустройства и текущие должности (`institution-staff`, `institution-positions`), квалификации и профессиональное развитие, контактные данные, историю посещаемости (`institution-staff-attendances`) и записи об отпусках (`institution-staff-leave`). Для записи — отметка присутствия или подача заявки на отпуск: см. [Отметка посещаемости персонала](playbooks/mark-staff-attendance.ru.md). Для полного профиля: [Просмотр профиля сотрудника](playbooks/view-staff-profile.ru.md).
