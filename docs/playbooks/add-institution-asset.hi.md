# किसी संस्थान में उपकरण या संपत्ति जोड़ें

**डोमेन:** अवसंरचना  
**दर्शक:** प्रशासक, लेखाकार, सुविधाएँ  
**प्लेबुक आईडी:** `add-institution-asset`

## विवरण

किसी संस्थान में नए अधिग्रहित उपकरण या संपत्ति दर्ज करें — कंप्यूटर, डेस्क, प्रोजेक्टर, फर्नीचर, या कोई भी भौतिक इन्वेंट्री आइटम। एक पंक्ति = एक भौतिक आइटम; एक से अधिक समान इकाइयाँ जोड़ने के लिए, प्रत्येक आइटम के लिए अलग-अलग `code` और `serial_number` के साथ एक रिकॉर्ड पोस्ट करें। `purchase_order` और `cost` को प्रत्येक लेखन में शामिल किया जाना चाहिए (सभी दस्तावेजित उदाहरणों में मौजूद — इसे आवश्यक मानें भले ही औपचारिक रूप से नल करने योग्य न हो)।

---

## पहले पूछे जाने वाले प्रश्न

कुछ भी लिखने से पहले, एजेंट को यह एकत्र करना होगा:

| प्रश्न | फ़ील्ड | नोट्स |
|---|---|---|
| किस प्रकार की संपत्ति? (जैसे लैपटॉप, कुर्सी, प्रोजेक्टर) | `description` | मुक्त पाठ — वर्णनात्मक रहें |
| कितनी इकाइयाँ? | (लूप काउंट) | प्रति इकाई एक POST |
| संपत्ति कोड / इन्वेंट्री टैग क्या है? | `code` | पूरे सिस्टम में अद्वितीय होना चाहिए, जैसे `AST-2025-001` |
| सीरियल नंबर? | `serial_number` | प्रति इकाई एक; अद्वितीय होना चाहिए |
| निर्माता / मेक? | `asset_make_id` | `asset-makes` के माध्यम से देखें; अज्ञात होने पर छोड़ दें |
| मॉडल? | `asset_model_id` | `asset-models` के माध्यम से देखें; अज्ञात होने पर छोड़ दें |
| खरीद आदेश संख्या? | `purchase_order` | PO संदर्भ, जैसे `PO/2025/045` |
| इकाई लागत? | `cost` | संख्यात्मक, जैसे `1250.00` |

---

## उपयोग किए गए संसाधन

| संसाधन | उद्देश्य |
|---|---|
| `asset-makes` | लुकअप: निर्माता सूची (Dell, HP, आदि) |
| `asset-models` | लुकअप: मॉडल सूची (वैकल्पिक) |
| `institution-assets` | लेखन: प्रति भौतिक इकाई एक रिकॉर्ड बनाएं |

---

## चरण

| चरण | क्रिया | संसाधन | उद्देश्य |
|---|---|---|---|
| 1 | `openemis_get` | `asset-makes` | मेक नाम → `asset_make_id` हल करें (मेक अज्ञात होने पर छोड़ दें) |
| 2 | `openemis_get` | `asset-models` | मॉडल नाम → `asset_model_id` हल करें (मॉडल अज्ञात होने पर छोड़ दें) |
| 3 | `openemis_create` × N | `institution-assets` | प्रति भौतिक इकाई एक रिकॉर्ड पोस्ट करें |

---

## चरण नोट्स

**चरण 1–2 — लुकअप (वैकल्पिक)**  
केवल तभी चलाएं जब उपयोगकर्ता कोई मेक या मॉडल प्रदान करता हो। नाम से फ़िल्टर करें: `GET /api/v5/asset-makes?name=Dell`। यदि कोई मिलान नहीं है, तो FK के बिना आगे बढ़ें — दोनों फ़ील्ड वैकल्पिक हैं। एक अमान्य `asset_make_id` को 422 के साथ अस्वीकार कर दिया जाएगा, इसलिए इसे केवल तभी भेजें जब आपके पास एक वैध ID हो।

**चरण 3 — संपत्ति रिकॉर्ड बनाएं**

प्रति इकाई POST बॉडी:
```json
{
  "code":           "AST-2025-001",
  "description":    "Dell OptiPlex 3090 Desktop Computer",
  "serial_number":  "SN-DELL-9988776655",
  "purchase_order": "PO/2025/045",
  "cost":           1250.00,
  "asset_make_id":  12,
  "asset_model_id": 45
}
```

N इकाइयों के लिए, अद्वितीय `code` (जैसे `AST-2025-001`, `AST-2025-002`) और अद्वितीय `serial_number` के साथ दोहराएं।

> ⚠️ **PUT को पूर्ण पेलोड की आवश्यकता है।** यदि किसी मौजूदा संपत्ति को अपडेट कर रहे हैं, तो पहले वर्तमान रिकॉर्ड प्राप्त करें, परिवर्तनों को मर्ज करें, फिर पूर्ण ऑब्जेक्ट PUT करें। किसी भी फ़ील्ड को छोड़ने से वह नल सेट हो जाती है।

---

## प्रमुख सावधानियाँ

- **एक पंक्ति = एक भौतिक आइटम।** कोई `quantity` फ़ील्ड नहीं है। "हमने 5 कंप्यूटर खरीदे" = 5 POST कॉल।
- **`code` पूरे सिस्टम में अद्वितीय होना चाहिए।** एक टकराव 409 लौटाता है। यदि उपयोगकर्ता के पास कोई मौजूदा परंपरा नहीं है, तो `{INSTITUTION_CODE}-{YEAR}-{SEQ}` जैसी योजना का सुझाव दें।
- **`purchase_order` और `cost` प्रत्येक दस्तावेजित उदाहरण में मौजूद हैं** — इन्हें प्रत्येक लेखन में शामिल करें।
- **`asset_make_id` और `asset_model_id` वैकल्पिक हैं** लेकिन यदि भेजे जाते हैं तो वैध ID होने चाहिए — एक अमान्य मान 422 का कारण बनता है, न कि एक मूक छोड़ना।
- **इस संसाधन पर कोई `academic_period_id` नहीं है** — इसे न भेजें।

## उदाहरण क्वेरी

> *"हमने पुस्तकालय के लिए 2 Dell लैपटॉप खरीदे — सीरियल नंबर SN-001 और SN-002, लागत प्रत्येक 1,100, PO/2025/071।"*

1. `openemis_get { resource: "asset-makes", params: { name: "Dell" } }` → id: 12
2. `openemis_create { resource: "institution-assets", body: { code: "LIB-2025-001", description: "Dell Laptop", serial_number: "SN-001", purchase_order: "PO/2025/071", cost: 1100.00, asset_make_id: 12 } }`
3. `openemis_create { resource: "institution-assets", body: { code: "LIB-2025-002", description: "Dell Laptop", serial_number: "SN-002", purchase_order: "PO/2025/071", cost: 1100.00, asset_make_id: 12 } }`
